3D Legacy Well Reviewer — interactive AOR & wellbore risk viewer (sites, 3D scene, screening model)

Open full screen ↗
The 3D reviewer keeps its own per-site datasets (autosaved in your browser). "Send register wells" pushes the current shared register into the active 3D site: wells with lat/lon inside the site frame are geolocated; wells without coordinates are parked on a flagged holding row. Both apps score on the same methodology (methodology.json) — pushes in either direction carry the 11 parameter scores losslessly. One click of Ctrl+Z inside the viewer reverts a send. The bridge is two-way: the viewer\u2019s toolbar gains a “⇧ Push to Register” button when embedded here, which maps its wells back into the shared register.

Shared Team Register — Sync Settings

This dashboard stores the well register in a shared file (wells.json) in the team's GitHub repository. Everyone who opens this page sees the same register, and every save is kept — with full change history — until someone deletes it. Viewing needs nothing. Saving needs a GitHub access token (entered once; this browser remembers it).

Getting a token (once, ~2 min):
  1. Open github.com/settings/personal-access-tokens/new (sign in to GitHub).
  2. Name it anything (e.g. "well dashboard"); set a long expiration.
  3. Repository access → Only select repositories → choose CO2_Legacy_wellbore_dashboard.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate, copy the token, and paste it above. A team token shared privately also works.

Methodology — rev

Edits commit methodology.json to the shared repo (needs the same token as well saves). Weight/band/unknown changes bump the minor version; wording changes bump the patch. Wells scored under older revisions are flagged for re-review — scores are never rewritten silently.
